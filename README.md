# EJERCICIOS_LEX
Repositorio académico de la asignatura Compiladores y Lenguajes de la Escuela Politécnica Nacional. Contiene ejercicios prácticos desarrollados con Lex/Flex y C en un entorno Linux, enfocados en el análisis léxico, reconocimiento de patrones, expresiones regulares, identificación de tokens y procesamiento de cadenas.
